# `HomeBook` / `mc_home`：Minecraft持久住宅登记

住宅设施事实存于部署的 `data/minecraft-home.json`，按存档身份隔离，每个存档一处当前家。它不保存人格记忆。2.2.0提供登记；2.3.0的住宅生活补丁提供建筑保护与夜间优先。

安装：`node patches/patch-minecraft-home.mjs`；只读验证：同一命令加 `--check`。锚点变化时停止，不拿旧`.orig`覆盖更新后的Cortico。模块、World工具接入、主进程环境摘要和快照摘要同步安装，不改Core。

流程：用户带她到房间并说“这是我们的家”；她调用 `mc_home` 的 `survey`，根据候选坐标问清自己的床、用户的床、共享箱子、工作台和炉子；确认后 `save`。`query` 返回历史登记及当前可读取状态：`present`存在、`occupied`被占用、`invalid`失效、`unloaded`尚未加载/当前维度不同/离线。不能从未加载推断被拆。

`save`必须含名称、用户确认说明及完整设施列表，自己的床恰好一张；角色为`own-bed`、`user-bed`、`shared-storage`、`workbench`、`furnace`。设施只接受现场32格内可核验对象。更新必须明确`replace:true`；`remove`同样需要用户确认说明。确认说明是模型依据对话记录的声明，不是权限认证系统，不保证模型不可能误填；工具契约要求不得虚构确认。

调查范围16格，以32格内的玩家Infinite为中心，否则以她为中心；只读已加载设施，最多扫描512格匹配方块、展示64个合并后候选，候选不等于归属。床统一保存头部坐标，使用时可以把该坐标交给现有`mc_do`的`use`动作。

按UUID使用既有`cortico-realm.json`身份；缺标记/外部服务器采用Cortico现有弱身份（地址及存档名）。弱身份不能辨别同地址被替换的远程世界，需用户重新核对，不承诺自动识别。

损坏或不兼容数据明确报错，保留原文件；登记采用临时文件和原子重命名。环境摘要只陈述历史登记，不宣称床仍然存在或已设置重生点。现场`query`不会更新人格记忆、重生点或游戏方块。

验证：`node --test addons/minecraft-home/tests/*.test.mjs`。真实验收由用户完成：现场认家、正常重启/交接后询问家和床、实际使用自己的床并核对游戏回执。

## 2.3.0 保护与夜间优先

先安装登记补丁，再运行 `node patches/patch-minecraft-home-life.mjs`，加`--check`只验证。两个补丁均预检锚点；源码变化时停止，不能用旧备份强制覆盖新版。

旧档案自动采用设施和返回位置的包围盒外扩水平6格、下2格、上6格；这是保守的保护范围，不代表程序推断出完整房屋轮廓。`mc_home query`返回当前边界。用户确认后可用`action:protect`及`protection:{min:[x,y,z],max:[x,y,z]}`调整，必须包含登记设施。没有无限期拆家豁免；本版不做装修授权系统。

范围内的资源候选会被过滤，显式dig与寻路挖掘统一禁止；普通走路、开门、开箱子和使用床不受阻。保护只控制她的挖掘，不阻止玩家、怪物、爆炸、火焰或方块自然更新，不是服务器领地插件。

游戏12000刻进入夜间优先，12542刻后使用自己的床；旧任务按执行器可恢复断点暂存，非幂等中断步骤不重复扣料。天亮后解除优先并按原断点规则恢复。普通新任务不接单，不能用`now`抢占；模型`mc_stop`不能取消夜间优先，用户仍可从控制台停止服务。紧急`mc_escape`及环境/受击求生保留，主动找怪暂停。

床被占用、失效或异维度时等待并只报告状态变化；路径或睡床失败每分钟最多自动尝试一次，每夜最多三次，不改做下矿。即时危险脱险后继续；夜间专用睡眠等待自然醒，12分钟异常上限，避免原60秒兜底主动叫醒。它并不是token休眠系统，QQ和其他正常模型事件仍可产生请求。

集成测试：用Cortico目录中的tsx运行本仓库`addons/minecraft-home/tests/executor-integration.mts`，验证实际队列与实际睡眠等待函数，使用假身体/可控时钟，不启动bot。

# `HomeBook` / `patch-minecraft-home-ledger.mjs`：住宅建筑账本验收

版本2.4.0。先完成住宅与生活补丁，再安装账本补丁；不自动启动或停止真实bot。运行中不覆盖`dist/web`，正常重启时由既有`bin/cortico.mjs`检测源码变化后构建。

## 使用

1. 在MC World的「数据」确认出现「住宅与建筑账本」。进入「住宅与建筑」，核对两张床、箱子、返回点与保护边界。
2. 对她说：“以家为中心，左右各12格不能破坏，先告诉我范围。”确认后让她保存；也可在管理页输入半径，确认坐标范围后保存。范围下4上16格，若房屋超出此高度须和她确认精确边界。
3. 站在自动农田旁，说：“这是我们的自动农田，请先和我确认保护范围。”也可用管理页填写名称、半径，确认调查中心及范围后保存。不能只凭建筑名称认定轮廓。
4. 在家附近点「调查附近设施」，确认已有工作台与炉子可用后逐项补登记；也可让她调查并登记。已有床和共享箱子不必重新登记。
5. 白天请她合成/熔炼，查看动作时间线回执是否使用现成工作站及坐标。即使背包带有备用，32格内有可用工作站也优先走过去使用。
6. 请她获取保护范围内的墙柱材料，确认受阻；另去范围外采集，确认可进行。不要主动拆除不可替代设施来测试。
7. 正常重启后询问家、自己的床、工作台、炉子及农田保护范围，并与账本核对。口头“记住了”不代替登记及游戏回执。

## 验证边界

- 模块测试覆盖旧文件兼容、建筑存档/维度隔离、明确更新、范围校验、损坏文件保留、床未加载时补登记、清除后合法重载。
- 假身体集成验证实际World的登记、保护、面板、离线代理清除与实际`ensureStation`复用；不调用模型或连接真实服务器。
- 真实ConsoleUi的DOM测试覆盖状态显示、取消确认不保存、确认范围保存、玩家中心建筑登记、共享炉子补登记和断线后按钮恢复。DOM测试不代表真实浏览器视觉验收。
- 全范围禁挖包括作物；本版不提供“只收成熟作物”的例外。容器库存仍由原容器账本管理。
- 登记中的确认说明由工具调用者填写，属于模型对用户确认的声明，不是独立授权认证机制。控制台保存会弹出确认框。
- 实际游戏中路径是否可达、边界是否覆盖完整建筑、炉子是否适用待用户验证。

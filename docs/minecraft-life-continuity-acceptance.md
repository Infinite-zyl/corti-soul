# 自主生活接续：2.12.0 实际验收

代码与产物交付，不预先标记生活行为通过。实现无新增模型、上游探针或自动bot启动。

1. 正常启动Cortico、服务器和观察者。MC World「数据」页查看生活计划账本：旧工程仍在；声明依据与实际执行回执分别展示。观察者保留任务面板，并增加目标、等待原因、复查时间。
2. 在游戏或QQ说：“你自己安排接下来的生活，记下目标和下一步；需要等我决定的事情单独挂起，可以做其他符合约定的事。没事做可以休息，记下原因。”这只是引导她首次登记，不是每次都要提醒。
3. 观察一个实际游戏昼夜：任务完成后是否安排下一步；晚上回家睡觉；早上读取现状后选择继续。允许她登记有原因、有复查条件的休息，不要求持续工作。
4. 让某一建设事项等你确认，同时允许另一项独立活动。她收到无关回复时不得自动把它视为建设批准；你不在线也不应取消全部生活安排。
5. 让她等待自己已观察到的一格作物成熟：未熟/未加载不假报成熟；成熟后只有一次对应接续提醒。炉子预计完成时仍需取货核验。
6. 正常重启Cortico：同一存档事项仍在，不重放旧动作；取消事项不复活。上下文交接后仍能查询计划与下一步。
7. 无明确条件休息时看现实5/15/30分钟复查；连续三次无进展后停止周期提醒。真实任务进展后才重置。模型退避/离线/夜间等阶段不应额外催醒。

发现问题请保留发生时间、事项ID、任务号及HUD截图，不需要持续盯日志。代码定向测试不代替上述实际验收；现有免费池消耗的长期统计另行讨论。

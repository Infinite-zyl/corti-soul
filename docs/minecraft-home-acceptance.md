# `mc_home`：2.2.0现场认家验收

代码、安装与定向检查已完成，真实认家、睡床和重启后的连续性待用户验收。没有自动创建真实住宅档案，没有启停bot或进入服务器。

## 现场操作

在正常停机窗口重启Cortico，使新增工具加载。你用Infinite身份进入原存档，带她进准备认领的房间。

1. 说“这里是我们的家，你先看看房间里的床和设施，别动东西”。她应调用`mc_home survey`，列出候选并问你归属；没有查到时应报告范围/未加载，不能声称没有床。
2. 明确指出她的床、你的床和可共享箱子；工作台、炉子存在时一并确认。你可用“左边/对面”等描述，但她必须把描述与现场坐标对上；有歧义就追问，不能随机认领。
3. 她应保存登记并复述家、自己的床及共享设施。你说“查一下我们的家”，应返回历史登记加现场存在/占用状态。
4. 正常重启Cortico或经历上下文交接后，再问“我们的家在哪，你的床是哪张”，应读到同一档案；暂时离家不能把未加载判成床被拆。
5. 晚上让她使用登记的自己的床，查看真实动作回执与重生点。此项尚未实现自动作息，不承诺她会主动夜间回家。

## 失败反馈

只记录出错的步骤、时间、原话与工具回执。不为了采证让她循环尝试，不继续到保护建筑等下一项。

这个版本不阻止拆家、不安排夜间作息，也不改死亡恢复。这些仍按生活优化计划逐项实现。

# `autonomy.ts` / `ProjectBook`：2.5.0自主生活验收

正常重启Cortico后生效；运行中的网页产物不覆盖，CLI在重启时检测源码变化并构建。无需重新登记家或调整你的保护范围。

1. 让她普通回家，查看实际步行回执。若调用`mc_escape`，无脱困失败证据应明确拒绝且不清空工作队列。不要主动把她困进危险环境测试。
2. 夜间再说“回家睡自己的床”，应返回已合并或实际休息状态；核对时间线没有因重复请求打断/重复排入睡床任务。其他工作仍暂停。
3. 查询建筑账本，旧农田/牧场应显示用户设施、未委托经营。确认她没有继续把收你的菜、修改你的保护范围当作自己的任务。
4. 白天观察她是否用`mc_project`登记自己的食物来源工程、在保护区外调查选址并执行下一步。受阻时应记录真实回执并换方法/地点，不把“没看到成熟作物”说成“被保护拦截”。
5. 在工程进行中正常重启，查询`mc_project`，核对目标、阶段、下一步保留；核对实际执行仍须看游戏回执。你离线不等于取消她自己的工程。

验证包括模块、真实World假身体和真实ConsoleUi DOM测试，不调用真实模型或连接服务器。代码/提示修正不等于已经证明模型长期自主运行；这部分由上述体验验收。

安装顺序：`patch-minecraft-home.mjs`、`patch-minecraft-home-life.mjs`、`patch-minecraft-home-ledger.mjs`、`patch-minecraft-autonomy.mjs`；四者加`--check`只检查。Core与通用控制台保持不变。

# `HomeBook.setEntrance` / `ModelRouting`：2.6.0验收

使用`launcher/releases/2.6.0/corti-soul启动器/corti-soul启动器.exe`，保留同目录`_internal`；旧启动器二进制不会获得新增按钮。正常重启Cortico后家门代码生效，CLI自动检测并构建控制台。没有替用户停止正在运行的游戏或切换实际模型。

## 家门

1. Infinite站在大门外1至3格，告诉她“这是家门，我站在门外，登记这个入口”；多门时确认所指木门。也可从住宅管理页调查附近设施，选择“登记为家门（我站门外）”。
2. 账本核对门、门内与门外落脚点。查询能区分未加载、失效和存在，并提供读取到的开关状态。
3. 白天让她从屋里到屋外，再从屋外回家。核对时间线及实际位置是否按入口通行；已开门不能被重复点击关上。
4. 这项不修改保护边界，不认领邻居房屋。台阶、双开门和复杂地形需核对站位；铁门暂不支持。

## 模型模式

1. 启动器“当前模型”下选择方式，点“刷新模型列表”；来源是Cortico已配置端点，不发送一次推理请求。
2. 选“手动固定”及主模型端点，点“应用”。先确认自动守护暂停，再激活所选端点；实际当前端点从Cortico回读。限流只报错，不因限流更换端点。模型自身重试、上游配额和`combo`端点内部降级不由启动器改写。
3. 关闭再打开启动器，模式应保留。配置仅存`guard/routing-mode.json`，不包含Key；侧调用模型保持原配置。
4. 选“自动切换”并应用，恢复现有守护的失败切换与恢复逻辑；手动期间的旧失败不应触发恢复后的立即换线。
5. 模型激活失败应保留手动模式并提示错误；停止守护失败则不切模型，恢复原模式。
